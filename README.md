# Dong / دُنگ — نسخه مستقل رسمی 1.0.0

**نام انگلیسی فقط Dong است.** این خط انتشار از صفر آغاز می‌شود؛ برنامه با شناسه تازه `ir.dong.household` نصب می‌شود و با نسخه‌های قدیمی `ir.dang.household` یا preview سازگاری نصب درجا ندارد.

## قابلیت‌ها
- مدیریت هزینه مشترک خانه، اعضا، صندوق، دنگ ماهانه، کارت‌ها، اقساط و دوره شمسی از مهر ۱۴۰۵
- ذخیره مالی آفلاین روی SQLite اختصاصی اندروید
- پیام موفقیت فقط بعد از ثبت در SQLite و گزارش خطا هنگام شکست ذخیره
- بک‌آپ خارجی استاندارد `.dongbak` بدون رمز در محل انتخابی کاربر با هش صحت SHA-256، و بازیابی با پیش‌نمایش و تأیید؛ پشتیبان‌های داخلی و امکان خواندن داده‌های رمزدار قدیمی نیز وجود دارد

## انتشار اصلی (قابل تکرار)
- نسخه `1.0.0`، `versionCode=16`، `applicationId=ir.dong.household`.
- گواهی ثابت SHA-256: `cd7c8d5ba5089ccaba2b235dfd3beb84ed86d7da9d2bf93c2faa7b676a3af360`.
- قالب کلید خصوصی **PKCS12** و alias `dong-release`. فایل کلید و رمز باید توسط مالک در محل خصوصی و مستقل نگهداری شود. آن‌ها نباید در GitHub یا چت عمومی منتشر شوند.
- فقط چهار Secret مالک `DONG_KEYSTORE_BASE64`, `DONG_KEYSTORE_PASSWORD`, `DONG_KEY_ALIAS`, `DONG_KEY_PASSWORD` اجازه امضای GitHub Release را دارند. `.github/workflows/build-apk.yml` صرفاً آزمون با signer موقت است و خروجی آن **قابل نصب به‌عنوان نسخه رسمی نیست**.
- `.github/workflows/release-production.yml` فقط روی main و با کنترل سخت هویت، امضا و نسخه اجرا می‌شود. برای نسخه‌های بعد از 1.0.0 اثبات ارتقای امضاشده بدون حذف داده لازم است.

## نسخه قدیم
نسخه‌های قدیمی به‌طور خودکار حذف نمی‌شوند. برای جلوگیری از از دست رفتن داده، قبل از حذف آن‌ها یک بک‌آپ بیرونی امن بسازید و صحت بازیابی را تأیید کنید. مهاجرت خودکار از دیتابیس قبلی به پکیج جدید انجام نمی‌شود.

## شواهد
کد این نسخه از V1 موفق در CI روی Commit `5ca388ca9383663315a96d7407103f0cd633a617` منشعب شد. APK مستقل اولیه با بازبسته‌بندی manifest/resource از همان build و امضای جدید تولید شده است؛ ساخت APK مستقل به معنی تست نصب روی گوشی واقعی نیست. گزارش نصب و تست on-device باید به‌صورت مجزا ثبت شود.
