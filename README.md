## معماری
- React 19 و Vite، WebView محلی بدون مجوز اینترنت و بدون وابستگی به سرور.
- SQLite بومی `dang.sqlite` در فضای خصوصی برنامه؛ تراکنش‌های revision-guarded و audit trail.
- بک‌آپ داخلی خودکار و دستی: تا ۶۰ snapshot خصوصی، سیاست هر تغییر، ساعتی/روزانه در بازکردن برنامه یا دستی.
- بک‌آپ **خارجی بدون رمز**: `.dangbak` نسخه‌دار، حاوی همه اطلاعات مالی و اثر انگشت SHA-256 کل داده. انتخاب محل با Android Storage Access Framework. فایل **به‌صورت متن ساده** ذخیره می‌شود؛ در محل امن نگهداری کنید.
- فایل‌های رمزگذاری‌شده قدیمی `dang-android-encrypted` همچنان قابل واردکردن‌اند و **تنها برای همان فایل‌های قدیمی** رمز قبلی ضروری است.
- Restore: تأیید فرمت، digest و قواعد مالی؛ پیش‌نمایش، تأیید کاربر، snapshot پیش از بازیابی، تراکنش SQLite و بازخوانی/مقایسه پس از بازیابی.
