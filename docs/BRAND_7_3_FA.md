# هویت بصری دنگ ۷.۳

منبع نام و نشان، فایل‌های ارسالی مالک `65843.png` و `65844.png` است. `65927.jpg` تصویر رابط قبلی است؛ برای پالت جدید به‌عنوان لوگو استفاده نشده است. متن و نشان بازطراحی نشده‌اند. فایل‌های وب فقط برای اندازه نمایش بهینه شده‌اند و نام فارسی از همان تصویر مالک برش خورده است. Adaptive و Monochrome به مسیرهای بومی از مرز چهار بخش نشان تبدیل شده‌اند؛ حاشیه امن Android رعایت شده است.

پالت رابط: سرمه‌ای `#062C5B`، مرجانی `#FF654F`، سفید گرم `#FCF9F3`، زمینه `#F7F8FC`. متن روی مرجانی استفاده نشده؛ برای دکمه اصلی، سفید روی سرمه‌ای به‌کار رفته است. معانی مالی موفق/خطا/هشدار علاوه بر رنگ با متن مشخص می‌شوند.

فونت متغیر Vazirmatn به‌صورت آفلاین در APK قرار دارد. منبع رسمی: https://github.com/rastikerdar/vazirmatn ؛ blob فونت `a501289a85595158570b0c2badcb4608b042e748` و مجوز SIL OFL در `public/fonts/OFL.txt` همراه برنامه است. وابستگی Google Fonts از CSS حذف شده است. ضخامت آیکون‌ها، خطوط، اندازه لمسی و رنگ‌های فعال هماهنگ شده‌اند.

نسخه Release: `7.3.0`، `versionCode=13`، شناسه ثابت `ir.dang.household`. نصب‌های `preview71`، `preview72` و `preview73` به‌طور خودکار به این شناسه تبدیل نمی‌شوند. نصب قدیمی حذف نمی‌شود. برای مهاجرت، بک‌آپ رمزگذاری‌شده از نصب قدیمی و اعتبارسنجی و بازیابی در نصب جدید لازم است. آزمون فایل‌گزین میان دو نصب روی گوشی مالک هنوز مستقل از آزمون خودکار باقی است.

کلید خصوصی Release خارج از مخزن عمومی ساخته و در پشتیبان خصوصی مالک حفظ می‌شود. هیچ کلید خصوصی، رمز یا محتویات پشتیبان در Git، Log یا Artifact عمومی قرار نمی‌گیرد. ورود Secrets در GitHub فقط توسط مالک انجام می‌شود. گواهی عمومی و اثر انگشت نهایی می‌توانند در گزارش انتشار ثبت شوند.

CI برای آزمون Release از یک کلید موقت صریحاً با عنوان CI validation only استفاده می‌کند. فایل تحویل مالک پس از دریافت Artifact با کلید خصوصی پایدار امضا می‌شود. برابری تمام ورودی‌های کاربردی APK قبل و بعد از امضا باید بررسی شود؛ تغییر امضا نباید dex، resources یا assetها را تغییر دهد. Artifact امضاشده موقت CI، فایل نهایی قابل تحویل نیست.
