## اصلاحات موجود در شاخه پیشنهادی
- نسخه بعدی `7.3.2` / `versionCode=15` است، چون کد امضاشدهٔ ۷.۳.۱ نباید با همان versionCode جایگزین شود.
- هویت اصلی در Gradle literal و غیرقابل تغییر با `-P` شده؛ `applicationIdSuffix` حذف شده.
- تست قدیمی اثبات نصب موازی حذف، آزمون contract هویت ثابت جایگزین شده است؛ CI تست به هیچ وجه Artifact قابل نصب نهایی ندارد.
- مسیر جدای انتشار با کلید اصلی و fingerprint ثابت ساخته شده، فقط روی `main` و فقط manual؛ ساخت موقت Debug/CI نمی‌تواند تبدیل به Release واقعی شود.
- تست `adb install -r` برای ۷.۳.۱ ← ۷.۳.۲ طراحی شده است؛ snapshot SQLite و بک‌آپ‌های خصوصی پیش/پس نصب با هم تطبیق داده می‌شود.
- بک‌آپ جدید `.dangbak` JSON سادهٔ بدون رمز همراه SHA-256 کل store دارد، در SAF نوشته می‌شود؛ بازرسی مالی، تأیید صریح، restore و readback دارد؛ فرمت رمزدار قدیمی برای بازیابی نگه داشته شده.
- `README.md` و `AGENTS.md` به روز شده‌اند؛ مرجع دائمی در `docs/ANDROID_RELEASE_BACKUP_POLICY_FA.md` است.
- فایل‌های تاریخی و APK واقعی قدیمی برای شواهد مهاجرت/آزمون **حذف نشده‌اند**؛ پاک کردن آن‌ها برای جلوگیری از نصب مجزا لازم نیست.
