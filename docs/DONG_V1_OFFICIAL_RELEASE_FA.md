- GitHub Actions در `.github/workflows/release-production.yml` از چهار Secret استفاده می‌کند:
  `DONG_KEYSTORE_BASE64`, `DONG_KEYSTORE_PASSWORD`, `DONG_KEY_ALIAS`, `DONG_KEY_PASSWORD`.
- هیچ کلید خصوصی یا رمز عبوری داخل این مخزن و این گزارش ثبت نشده است.
- تمام آپدیت‌های بعدی باید همین `applicationId` و همین گواهی را حفظ کرده و `versionCode` را افزایش دهند؛ هر نسخه بعدی قبل از انتشار باید تست `adb install -r`، بقا و بازخوانی SQLite و صحت بک‌آپ را بگذراند.
- APKهای امضاشده با کلید موقت CI **هرگز** مبنای انتشار رسمی نیستند.
