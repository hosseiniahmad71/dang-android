## قابلیت جدید

در «تنظیمات و امنیت دُنگ ← تنظیمات پایه صندوق و دنگ»، گزینه «شروع دوره‌های دنگ» فعال شد. با انتخاب آبان ۱۴۰۵، ماه‌های پیش از آبان در انتخاب دوره مالی، تخصیص دنگ، فرم‌های مالی و تقویم شمسی غیرمجاز می‌شوند؛ تعهد ماه مهر صفر است و سابقهٔ بدهی از آبان شروع می‌شود. حداقل تاریخ پشتیبانی‌شده **مهر ۱۴۰۵** باقی مانده و مقدار پیش‌فرض همچنان مهر است؛ کاربر می‌تواند مقدار را تغییر دهد.

تغییر تاریخ شروع **هیچ‌یک از داده‌های قبلی را حذف نمی‌کند**. جابه‌جایی رو به جلو تنها هنگامی مجاز است که هیچ سند مالی، قرارداد/قسط، تنظیم مبلغ ماهانه یا ماه قفل‌شده‌ای پیش از تاریخ پیشنهادی باقی نماند. این شرط هم در UI و هم در موتور تراکنشی SQLite اندروید و مسیر سرور Termux بررسی می‌شود. شروع دوره در Store ذخیره می‌شود و همراه بک‌آپ قابل بازیابی است.

## مشخصات نسخه امضاشده

- فایل تحویلی در گفتگو: `Dong-v1.0.1-Update.apk` — نسخه جدیدی از **همان** بسته.
- `applicationId`: `ir.dong.household` (همان V1.0.0).
- `versionName`: `1.0.1` — `versionCode`: **17** (قبلی 16).
- SHA-256 فایل APK: `011612c47f150735f31fe286f43510fdbe6cb37b7ecfaf0f402e9bc03dd31f1f`.
- SHA-256 گواهی امضای مالک، مشابه Dong V1.0.0: `8f5ee72bc0e7586b8b6188e6817f4c616bad2df7546da7595291e7ea36911d93`.
- امضای APK V2 و V3 با `apksigner verify` تأیید شد.
- همه ۱۹ ورودی غیرامضای APK امضاشده با خروجی ساخته و اعتبارسنجی‌شدهٔ CI از نظر محتوای بایت‌ها تطبیق دارند.
- آزمون‌های TypeScript، قرارداد مالی، حسابرسی و ساخت Gradle موفق شدند. آزمایش instrumented روی شبیه‌ساز Android 15/API 35: **یک سناریوی یکپارچه؛ ۰ شکست و ۰ خطا**. آزمون شامل WebView، فرم‌ها و SQLite بوده است.
- **محدودیت تست:** دستور `adb install -r` روی گوشی واقعی مالک اجرا نشده است. قبل از نصب، یک نسخه بک‌آپ مستقل از اطلاعات تهیه شود.

## زنجیره امضا و آپدیت

این فایل با **همان کلید خصوصی پایدار Dong 1.0.0** که در تحویل پایه نزد مالک نگهداری می‌شود، امضا شد؛ هیچ امضاکننده آزمایشی/CI مبنای آپدیت کاربران نیست. کلید و رمزهای آن نباید در GitHub عمومی، Issue، Log یا چت منتشر شوند. تمام نسخه‌های آینده باید همین `applicationId` و همین گواهی را نگه دارند و `versionCode` را افزایش دهند.

خط قدیمی `ir.dang.household` متفاوت است و این فایل آن را آپدیت نمی‌کند. Dong V1.0.1 روی Dong V1.0.0 نصب می‌شود، نه روی Dang 7.x. دادهٔ گوشی‌های قبلی از راه دور پاک نشده است.
