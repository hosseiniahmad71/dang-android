## کنترل‌های پیاده‌سازی‌شده
- تغییر Gradle به `applicationId` دائمی بدون suffix یا پرچم تغییر؛ نسخه V1.0.0/code16.
- workflow مستقل CI با signer دورریختنی و Artifacts دارای برچسب `DO-NOT-INSTALL`.
- workflow مستقل Release با کلید ثابت مالک، بررسی pin امضا و versionCode، و اجرای `adb install -r` روی APK اصلی قبلی، شامل snapshot کامل SQLite و backup.
- پشتیبان خارجی جدید `.dangbak`: قالب `dang-portable-backup`، `schema=3`، plaintext بدون رمز، SHA-256، تأیید پیش از restore، اعتبارسنجی مالی و readback.
- خواندن بک‌آپ‌های رمزدار قدیمی بدون حذف قابلیت decrypt؛ رمز قدیمی فقط در همین حالت الزامی است.
- AGENTS.md و سیاست Release برای تکرارناپذیری مشکل امضا/شناسه.
- پاکسازی فایل‌های منسوخ فقط در working tree و با حفظ تاریخچه Git؛ APK مبنای ۷.۳.۱ و تست‌های مالی جاری باید باقی بمانند.
