# دنگ v6 — React 19 + SQLite مستقل + ممیزی ۱۲ ماه

برنامه فارسی و راست‌چین مدیریت صندوق و دنگ خانواده، مخصوص Termux/Android و یک مدیر.

## چه چیزهایی در نسخه ششم تغییر کرد؟

- همه بخش‌های تنظیمات همچنان جمع‌شونده‌اند و پیش‌فرض بسته می‌مانند.
- مبدأ وجه اصلاح شد: انتقال از صندوق به کارت دیگر به‌عنوان **وجه امانی صندوق** ردیابی می‌شود؛ خرید از همان وجه اعتبار دنگ شخصی ایجاد نمی‌کند.
- مانده صندوق در داشبورد مطابق **انتهای ماه شمسی انتخاب‌شده** است، نه همیشه آخرین مانده موجود.
- کنترل کمبود وجه براساس **تاریخ واقعی** تمام رویدادها انجام می‌شود، نه ترتیب اضافه‌شدن آن‌ها.
- بخش تاریخچه: **ابطال سند با علت و سابقه برگشت**، و **اصلاح مبلغ به‌صورت اتمیک** با سند برگشتی + سند جایگزین. اصلاح سایر فیلدها از مسیر ابطال و ثبت صحیح انجام می‌شود.
- بخش تنظیمات: **قفل/بازگشایی ماه با دلیل**؛ هیچ رویداد تازه‌ای در ماه بسته ثبت نمی‌شود.
- تغییر تعهد ماه دارای تراکنش با **سند تعدیل قابل‌ردیابی** انجام می‌شود، نه بازنویسی خام ارقام.
- بک‌آپ مستقل SQLite با **AES-256-GCM** در حافظه اشتراکی گوشی (`~/storage/downloads/DangBackups`) و بازیابی با رمز. Google Drive در رابط نسخه ششم کنار گذاشته شده است.
- بک‌آپ‌های داخلی بعد از تغییر یا ساعتی/روزانه همچنان پشتیبانی می‌شوند؛ زمان‌بندی هنگام خاموش‌بودن Termux اجرا نمی‌شود.

## نصب با حفظ نسخه قبل

**دستورها را در Termux اجرا کنید.** اگر نسخه ۵ روشن است، ابتدا با Ctrl+C آن را متوقف کنید و از مسیر تنظیمات آن یک پشتیبان مستقل بگیرید.

```bash
termux-setup-storage
cd ~
cp ~/storage/downloads/dang-react19-v6-sqlite-audited.zip ~/ 
unzip -o dang-react19-v6-sqlite-audited.zip
cd ~/dang-v6
npm install
npm run test:server
npm run test:ui-contract
npm run test:audit
npm run build
npm start
```

برنامه در `http://127.0.0.1:8787/` باز می‌شود. فایل دیتابیس اصلی همان `~/dang-data/dang.sqlite` است؛ اجرای v6 یک پوشه پروژه مجزا می‌سازد و اطلاعات نسخه ۵ را عمداً پاک نمی‌کند. ساختارهای جدید SQLite در زمان اولین راه‌اندازی افزوده می‌شوند. **از نصب، حذف داده Termux، و Restore فایل ساختگی روی دیتابیس اصلی خودداری کنید.**

## بک‌آپ رمزگذاری‌شده خارجی

1. پس از اجرای `termux-setup-storage` و اعطای مجوز حافظه، به **تنظیمات → پشتیبان رمزگذاری‌شده خارج از Termux** بروید.
2. رمز قوی حداقل ۱۲ نویسه‌ای انتخاب کنید. رمز را خارج از گوشی نگه دارید؛ فراموشی رمز یعنی عدم امکان بازیابی.
3. روی «ساخت بک‌آپ مستقل در Downloads» بزنید. نتیجه در `Downloads/DangBackups/*.dangbak` نگهداری می‌شود.
4. برای بازیابی، همان فایل و رمز را در همین بخش انتخاب کنید. عملیات بازیابی قبل از جایگزینی SQLite از وضعیت قبلی هم نسخه تهیه می‌کند.

برای بک‌آپ **خودکار خارجی** در هر رویداد/زمان‌بندی، هنگام روشن‌کردن سرور، با ورودی بدون نمایش رمز وارد کنید:

```bash
cd ~/dang-v6
read -rsp 'رمز بک‌آپ خارجی: ' DANG_BACKUP_PASSPHRASE; echo
export DANG_BACKUP_PASSPHRASE
export DANG_EXTERNAL_BACKUP_DIR="$HOME/storage/downloads/DangBackups"
npm start
```

رمز نباید در دستور خط فرمان به‌صورت مستقیم تایپ شود تا در تاریخچه Shell نماند. اگر Termux بسته شود، زمان‌بندی ساعتی/روزانه تضمین نمی‌شود. نگهداری فایل در Downloads همان گوشی از اطلاعات در برابر خرابی یا گم‌شدن کل دستگاه محافظت نمی‌کند؛ از چند نسخه رمزگذاری‌شده روی دستگاه دوم هم نگهداری کنید.

## آزمون‌ها

```bash
npm run test:server       # SQLite + API + 12-month integration
npm run test:ui-contract  # Accordion و راهنماهای عملیات
npm run test:audit        # 373 مقایسه فرمول‌های واقعی UI با داده‌های 12 ماه
npm run build             # بررسی Typescript و تولید برنامه React/Vite
```

نتیجه اجرای ممیزی در این بسته: `AUDIT_12_MONTHS.md` و `AUDIT_12_MONTHS_DATA.json`. داده‌های آزمایشی تنها در کد تست وجود دارند. **فایل آزمایشی را در برنامه اصلی Restore نکنید.**

## محدودیت‌های مهم

- مانده کارت‌های شخصی به‌صورت گردش بانکی مستقل محاسبه نمی‌شود؛ فقط وجه امانی مشترک صندوق نزد کارت‌ها کنترل می‌شود.
- پرداخت نیابتی از کارت فرد دیگر تا زمان وجود سند مالکیت جداگانه پذیرفته نمی‌شود.
- احراز هویت مستقل با PIN هنوز اجرا نشده است؛ Node روی لوپ‌بک محلی اجرا می‌شود ولی این به معنی حفاظت کامل از سایر پردازش‌های همان گوشی نیست.
- اجرای مرورگری و `npm run build` در محیط ساخت این بسته به‌دلیل دسترسی‌نداشتن به npm Registry تأیید نشد. کاربر باید اجرای واقعی روی Termux را آزمون کند.
- SQLite مستقل از مرورگر است ولی اپلیکیشن تا روشن‌بودن سرور Termux کار می‌کند.
- خروجی JSON بدون رمز در تنظیماتِ قدیمی وجود دارد؛ این فایل را ناامن منتشر نکنید. برای اطلاعات حساس، خروجی رمزگذاری‌شده `.dangbak` ترجیح دارد.
